# 掼蛋教练 · 边打边学

给"看得懂牌、但一上桌就懵"的人准备的掼蛋教学网页。
不是又一个掼蛋游戏 —— 它把牌局拆开给你看：**这手牌叫什么、能和什么比、该怎么拆、这一手为什么这么出**。

核心是第 5 页：**和 AI 队友、AI 对手打完整一副牌，每一手都有教练给建议和理由**。
前 4 页是上桌前的热身，随时可以回去查。

## 打开方式

**双击 `index.html`** 即可（Chrome / Edge），无需安装、无需联网。

如果浏览器拦截了本地脚本（极少见），在工作目录执行：

```powershell
python -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 上线分享（做成一个网址）

整个程序是**纯静态**的：没有后端、没有数据库、不需要编译，总共约 150KB，没有引用任何 CDN 或外部字体。所以"上线"等于"把文件夹传到任何静态托管"。

## 五个页面

| 页面 | 解决什么问题 |
|---|---|
| **05 实战对局** | 你 + 队友 vs 两个对手，完整一副牌：出牌、过牌、接风、进贡还贡、升级、过 A。每一手都有教练建议 |
| 01 牌力速查 | 牌谁大谁小？十种牌型长什么样？炸弹到底谁大？一局流程、进贡还贡 |
| 02 牌型判定 | 看到一手牌叫不出名字 → 限时点选，练到条件反射；"比大小"模式专练炸弹序列 |
| 03 逢人配实验室 | 红桃级牌是万能牌，能配出什么完全没概念 → 亲手摆，实时出结果 |
| 04 拆牌教练 | 27 张怎么分成几手 → 参考拆法 + 教练点评 |

### 05 实战对局怎么玩

- **座位**：下方是你，上方是队友（对家），左右是两个对手。出牌顺序逆时针：你 → 下家 → 队友 → 上家。
- **选牌**：点手牌选中（会弹起来），再点取消。选完会实时告诉你"已选 5 张 · 顺子 3·4·5·6·7"，或者"不成牌型"。
- **按钮**：出牌 / 过 / 提示 / 清空。快捷键 `Enter` 出牌、`空格` 过、`H` 提示。
- **记牌器**：牌桌下方那一条。它把"你的手牌 + 场上已经出过的牌"减掉，推算出**外面还剩什么**：
  每个点数还剩几张、逢人配还剩几张、以及**外面大概还有几个炸弹**（按"这几张得落在同一个人手里"算概率，不是简单数 4 张）。
  0 张的会变灰，可能成炸的点数会标红。
- **教练**：轮到你时自动给建议，点「提示」会直接把建议的牌帮你选好。建议里会带一句**记牌判断**，例如"外面已经没有能压过它的牌了""外面还有约 3 手能压过它"。右上角可以关掉教练。
- **难度**：新手 / 普通 / 高手（影响 AI 的炸弹时机、让牌判断、抢牌权激进程度）。
- **结算**：一副打完显示名次、升几级、下一副谁打谁；进贡/还贡自动处理并在记录里写明。

### AI 对手会记牌吗

会，但**只用在它算得准的地方**，这一点是用对局实验调出来的：

| 用途 | 做法 | 实测效果 |
|---|---|---|
| 炸弹更谨慎 | 记牌推断"外面可能还有更大的炸弹/天王炸"时，不急着把炸弹交出去 | ✅ 计入净收益 |
| 憋牌 | 为压一手小牌要拆掉已成型牌型（尤其动逢人配）时，对手还不着急就选择过 | ✅ 计入净收益 |
| 单张不送人头 | 对手只剩 1 张时，领单张只挑外面压不住的 | ➖ 中性（保留，不算收益） |
| 挑"最难被压"的牌去打 | 曾尝试：同样代价下优先出外面压不住的那手 | ❌ 反而更差，已回退 —— 会提前烧掉控制牌 |

**净效果**（同一副牌打两遍、红蓝对调，各 500 局）：

- 记牌版胜率 **53.6%**，旧版 46.4%（+7.2 个百分点），名次分 +0.296 分/局（2σ=0.217，**显著**）
- 对照组（两边同逻辑）只有 +1.6%、+0.056±0.194，证明不是噪声

复现实验：`node tests/ai-strength.js 250 all`（对照组用 `none`）。

### 规则实现口径

- 逆时针出牌；跟牌必须同牌型更大，或炸弹家族；其余人全过则最后出牌的人领出
- **接风**：队友打完最后一手、其余人都压不住 → 由你领出
- **升级**：头游 + 二游升 3 级、+ 三游升 2 级、+ 末游升 1 级
- **过 A**：A 必须打；头游 + 队友二游或三游才算过 A，否则继续打 A
- **进贡**：末游（双下则三游 + 末游）把最大的牌进贡给头游（**红桃级牌除外**，其他花色级牌可以进贡），头游还一张 ≤10 的牌；应进贡方抓到两张大王可以**抗贡**，改由头游先出
- **双下进贡同点**：按官方《竞技掼蛋竞赛规则(试行)2023》，两家进贡点数相同时按顺时针方向进贡，由**头游下家**先出（对应「进贡给头游者首圈领出」）
- **还牌兜底**：若全手牌均大于 10，则还最小的牌（官方条款）
- **接风（借风）**：某人出完最后一手牌且其他人都放弃，下一圈由其对家领出；**若对家也已走完，则顺延至其下家**
- **牌力 / 牌型**：`2<…<A<级牌<小王<大王`；级牌可按原始点数参与顺子/连对/钢板；红桃级牌 = 逢人配；炸弹家族 `4炸 < 5炸 < 同花顺 < 6炸 < 7炸 … < 四大天王`；三带二只比三张

（本机 PowerShell 执行策略可能禁止 `npm`，所以直接用 node 跑；也可以用 `npm.cmd test`。）

对局测试里最有价值的两条：

1. **AI 自对弈压测**：让 4 个 AI 打完整比赛，校验每一步合法、牌数守恒（手牌 + 已出 = 108）、名次不重复、升级数与名次一致。这条测试抓出过一个致命 bug —— `play()` 忘了推进轮次，结果一家能连出。
2. **强不变量**：出牌后必须轮到别家，绝不能同一家连出。

## 已知限制

- AI 是**启发式 + 记牌**，不是高手：会保留炸弹、给队友让牌、对手快走完时拦截，现在还会记牌和估炸弹概率；但没有搜索，不会推算你手里具体是什么牌（信息上也做不到）。难度三档差别有限。
- **进贡/还贡是自动的**（自动挑最大牌进贡、自动还最小牌），不能手动选还哪张。
- 拆牌是**启发式**（随机多次取较优），不保证全局最优，页面已标注"参考拆法"。
- 教练建议基于当前手牌的启发式评估，不是胜率计算。
- 仅适配桌面/普通移动浏览器，超小屏（< 360px）未优化。
